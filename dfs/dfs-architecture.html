Upgrade plan

  1. PHP 8.3 code fixes32 compatibility errors, SFTP library, click path. Tested locally against a copy of the feed config.
  2. Build the CX23Ubuntu 24.04, Nginx, PHP 8.3, MariaDB. Move the database to InnoDB and UTF-8.
  3. Run imports in parallelNew server imports the same feeds while Linode stays live. Compare row counts per feed.
  4. Price export + click.phpNightly JSON per shoe, all countries, with a timestamp.
  5. Theme change on stagingPrice boxes read the JSON, default US price in the HTML, "Prices as of" stamp, replacement for [dfscat].
  6. Switch overCompare prices old vs new, point WordPress and /go/ at the new server, cancel Linode after two weeks.

Found during the audit

  • Fix
    The click redirect still contains a create_function branch, removed in PHP 8. No parser uses it today, so it can simply be deleted.
  • Blocker
    The bundled SFTP library predates PHP 7 and already throws warnings on every CJ download.
  • Fix
    Amazon DE and IT are empty and CA is frozen. Only US and UK pull live prices.
  • Fix
    The [dfscat] shortcode sends raw SQL to DFS. It needs a replacement in the theme.
  • Fix
    Amazon requires a date/time stamp next to prices refreshed less often than hourly.
  • Fix
    Root SSH login by password. Credentials are also stored in plain text in the project notes.
  • Note
    46 of 82 feeds are failed, suspended or never set up. Zappos alone is 55% of all rows.
  • Note
    The API is now called from 65.181.124.237, not the IP in the notes. /go/ has the DFS IP hard-coded.
