## Verdict in one line
About 9,000 lines of logic sit in the theme. The 2026 code (schema, quiz capture, content dates, price box) is sound and moves with small fixes. The old code (SEO layer, comments/user reviews, quiz ranking, image resizer, related posts) is 2010–2018 plugin forks and copy-paste: it works, but has **real security holes** and should be rewritten, not moved.

## Security findings (fix first, independent of the move)
| # | Where | Problem | Severity |
|---|---|---|---|
| S1 | `includes/plugins/seo.php` `does_post_exist()` (404 → "permalink changed" redirect, option `psp_permalink_redirect` = **on** on live) | Raw request path pasted into SQL (`post_name = "<slug>"`). A probe with raw quotes got **403 from the edge** on staging, so Cloudflare/Rocket.net blocks the easy route today; the origin code is still injectable. WordPress core already does this redirect safely (`redirect_guess_404_permalink`). | High |
| S2 | `functions.php` `RSG_post_user_review_callback` (public AJAX) | Anyone can create a comment of **any type** on **any post ID**, with **any `meta_*` comment meta**. Also: both AJAX handlers echoed the request token back as HTML (`Security check<value>`, reflected XSS on admin-ajax.php, confirmed on live). | High |
