## 3. Fix (all 45 flagged)
One rule for every photo: opaque ones go through Pixian (same background removal as the upload hook, without its
1280x960 upscale); then every file is cropped to the shoe and centred on a transparent 4:3 canvas with a 1% margin
(never upscaled). Pixian: 38 calls, all OK. Before/after: `before-after-pricecard.jpg`, `before-after-other.jpg`.

Applied on staging, then live (live: `apply-live.sh`, file names `<model>-cut-out.png`): each new PNG imported as a new attachment of its review (`wp media import`), the review's
`professional_image` points at it, the old id is kept in `_rsg_prev_professional_image`. Old files untouched.
- Revert (per post): `wp post meta update <pid> professional_image $(wp post meta get <pid> _rsg_prev_professional_image)`.
- Server files: `~/rsg_tmp/cutfix/` (out/<old att>.png, named/, fix.tsv, apply.sh / apply-live.sh, apply.log / apply-live.log = post, old id, new id).
