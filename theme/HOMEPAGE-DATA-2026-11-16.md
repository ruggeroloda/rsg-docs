## Implications for the homepage redesign
- Google treats the homepage as RSG's **review + comparison hub**: H1/title/intro should say that plainly.
- Main job = routing into reviews (brand visitors know what they want → prominent shoe search / browse by type and brand).
- A "compare two shoes" entry point matches the comparison queries.
- "Best running shoes": one page must own it. Proposal: `/top/best-running-shoes-right-now/` owns it; homepage shows a short picks teaser linking there (avoid duplicating the full list).
- Organization schema + consistent name to consolidate the name variants.
- Homepage has no ads except the video unit → its revenue is the clicks it routes.
