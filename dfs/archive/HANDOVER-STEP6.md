## Gotchas learned in 6.1/6.2
- WordPress merges JSON body params before URL params: never read the post ID with `$req['id']`.
- Cloudflare 429 after ~200 REST calls at ~2.8/s from Hetzner: push paces 0.5 s and retries on 429.
- Rocket.net `CDN_HTML_PURGE*` are false, so the host helper can't purge by tag; our `/purge` route does.
- Push code deploy: `rsync -a --exclude .git --exclude __pycache__ app/ ruggero@116.203.146.177:/home/ruggero/dfs/app/` then `docker compose up -d --build` in `/home/ruggero/dfs/app/docker`. Receiver deploy: scp the file to staging, lint, copy to `wp-content/mu-plugins/`.
