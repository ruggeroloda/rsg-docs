## Recommendations, ranked by expected positive effect

### 1. Refresh the stale evergreen comparisons — biggest lever
- **Finding:** of ~90 versionless comparisons (`/comparison/a-vs-b/`), **39 compare an older model than RSG's newest review** of that line. They earned **~4,150 clicks / 238k impressions** in 28 days (21 % of comparison clicks, ~8 % of the whole site).
- Top ones (clicks 28d → stale side): Nimbus vs Cumulus 555 (Cumulus 27 → 28 reviewed) · Ghost vs Adrenaline 550 (GTS 23 → 25) · Ghost vs Glycerin 320 (Glycerin 21 → 23) · Pegasus vs Vomero 305 (Pegasus 41 → 42) · Winflo vs Pegasus 221 (41 → 42) · Cumulus vs Novablast 220 (Cumulus 26 → 28) · Cumulus vs Kayano 182 · Metcon vs Nano 153 (Metcon 6 / Nano X → Metcon 9 / Nano X4) · Glycerin vs Glycerin GTS 144 (21/20 → 23/22) · Ride vs Triumph 143 (Triumph 22 → 23) · Pegasus vs Structure 141 (Structure 25 → 26) · Pegasus vs Ultraboost 139 · Cumulus vs Ghost 131 · Wave Rider vs Inspire 114 (28/20 → 29/21). Full list: `stale.py` output (a few may be false matches; check each).
- **Why it matters:** searchers type versions ("hoka bondi 9 vs clifton 10", "clifton 11 vs bondi 9"); Google and AI answers prefer the page that names the current model; an outdated pairing contradicts RSG's own newer review on the same site.
- **Do:** (a) re-point each to the newest reviewed versions and refresh the verdict/"buy if" text, highest clicks first (top 14 ≈ 3,400 clicks); (b) put the versions in the title for versionless pages, e.g. "Nike Pegasus vs Vomero: Pegasus 42 vs Vomero 18 Compared"; (c) a weekly check (rsgmedia, same data as `stale.py`) that lists any comparison whose shoe has a newer review, so this never drifts again.
- **Effort:** mostly editorial (text names the versions); small code for title + checker.
