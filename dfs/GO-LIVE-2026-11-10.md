## Lessons (rules for next time)
- **Copy files one by one** onto the live theme; never extract a tar over existing trees (modes get reset).
- **Before overwriting a live file from the repo, diff live vs repo first.**
- **Every cache layer, not just page + CDN:** WP Rocket page cache (off), used CSS (RUCSS), **minified JS/CSS copies in `wp-content/cache/min/`**, Cloudflare. After editing `rsg-dfs.js`, refresh the min copy (copy the file over it + regenerate `.gz`, which changes its mtime and so the `ver=`), then `wp cdn purge`. Do not delete the min file instead: cached pages would 404.
- Check styling by "the CSS rules exist anywhere in the page", not "an inline style tag exists".
- `wp eval "rocket_clean_domain();"` does not clear `cache/min`.
- The cloud shell cannot reach Rocket.net; the SSH key lives on the Mac (`theme/.ssh-rocket-key`). If the Mac link drops, live data cannot be read.

## How to read the data
```
wp db query "SELECT COUNT(*) views, SUM(vis) visits, SUM(want<>'' AND want=hdr) agree, SUM(want<>'' AND want<>hdr) mismatch, SUM(src='f') trace_failed FROM newguru_wp_rsg_views"
wp db query "SELECT hdr, country shown, COUNT(*) n FROM newguru_wp_rsg_clicks WHERE want<>'' GROUP BY 1,2 ORDER BY n DESC"
```
Tables: `newguru_wp_rsg_views` (ts, page_id, country shown, want, src c/t/f/p, hdr, vis), `newguru_wp_rsg_clicks` (+ box, shoe, merchant, gender). Endpoints `POST /wp-json/rsg-dfs/v1/click` and `/view`. Country codes only, no IP, no user agent. Commits: `a4e07f3` (clicks v2), `259ab56` (view log).
